# AlphaForge AI 🚀

AI-Powered Financial Intelligence Assistant built using Multi-Agent AI workflows, LangGraph orchestration, FastAPI, React, and real-time market analysis.

---

## 📌 Overview

AlphaForge AI is an intelligent financial analysis platform that combines:

- Multi-Agent AI systems
- Real-time cryptocurrency market tracking
- AI-generated investment insights
- Risk analysis pipelines
- Financial news analysis
- LangGraph workflow orchestration
- Langfuse observability & tracing
- RAG-ready architecture

The platform analyzes financial queries and generates structured AI-driven insights for users interested in cryptocurrency and market trends.

---

##  Features

### 🤖 Multi-Agent Financial AI
- News Analysis Agent
- Risk Analysis Agent
- Market Analysis Agent
- Final Decision/Insight Agent

###  Real-Time Market Dashboard
- Live BTC, ETH, and SOL market tracking
- Integrated using `yfinance`
- Dynamic frontend market cards

###  AI Workflow Orchestration
- Built using LangGraph
- Modular multi-agent execution pipeline
- Structured state management

###  RAG-Ready Architecture
- ChromaDB vector database integration
- HuggingFace embeddings pipeline
- Retrieval-Augmented Generation support

###  Observability
- Langfuse tracing integration
- AI workflow monitoring
- Query-response tracking

###  Full Stack Architecture
- FastAPI backend
- React frontend
- REST API communication
- Responsive modern UI
